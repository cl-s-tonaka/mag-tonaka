# 要件定義書（第一段階 / 将来拡張前提）

## 1. 背景・目的
分散するナレッジおよび操作要求を、単一のチャットUIから扱える
AIエージェント基盤を構築する。

最終的には「情報参照」に加え、
- サブエージェントの自動生成
- GitHubへのコード反映（承認付き）
までを安全に実現する。

## 2. ゴール（最終形）
- ユーザーは自然文で依頼できる
- メインエージェントがサブエージェントを統制
- モード切替によりコード変更可否を厳密制御
- GitHub連携によりエージェント生成を自動化

## 3. 第一段階（MVP）のゴール
- GUI付きチャットアプリが動作する
- 既存のエージェント一覧が表示される
- メイン → サブ（1体）の委譲構造が成立
- ローカルナレッジ検索＋参照元提示が可能
- 将来拡張のための仕様が文書化されている

## 4. ユーザーストーリー（第一段階）
- ユーザーはチャットで質問できる
- 回答と共に参照元を確認できる
- チャットモード／エージェント作成モードを切り替えられる
- 作成モードでは未実装であることが明示される
- エージェント一覧が閲覧できる

## 5. スコープ
### 含む
- Next.js フロントエンド
- VoltAgent バックエンド
- LocalDocs 検索
- 仕様書・実装計画・進捗管理ドキュメント

### 含まない（第一段階）
- Google Drive / Slack / AWS 連携
- GitHubへの自動コミット・PR
- 認証・権限管理
- 自律的なファイル改変
